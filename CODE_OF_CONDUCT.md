# Code of Conduct

SkyBrowse follows the spirit of the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html): be respectful, be kind, give constructive feedback, and don't harass or demean anyone. Issues and pull requests are collaborative spaces — treat them that way.

Violations can be reported by opening an issue titled "Code of conduct" with no public details, or via GitHub's private vulnerability/contact reporting if enabled. Maintainers may remove comments, close issues, or block users when necessary.
